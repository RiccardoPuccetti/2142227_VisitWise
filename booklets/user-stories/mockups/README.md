# LoFi Mockups

One mockup per screen. Every user story points to its screen in `../USER_STORIES.md`, so each story has a mockup.

Screens S1-S6 and S11-S13 are drawn in Balsamiq (`.bmpr` source + PNG export). Screens S7-S10 (Marzella) have no
Balsamiq source: the PNG files are generated by `tools/GenerateMockups.java` (see "Generated mockups" below).

Rules

- Export every mockup as PNG with the same name (PNG is what the booklet and the slides embed).
- Annotate non-functional requirements directly on the mockup when they affect the UI (e.g. "progress refreshes every 3 s").
- Mockups are LoFi: grayscale, no real data (NDA) - use the synthetic sample names.

## Generated mockups (S7-S10)

`tools/GenerateMockups.java` is a single-file Java program (Java2D, no dependencies) that draws the four planner
screens in grayscale at 1280 x 900 and writes the PNG files. It is the source of those mockups: edit the program,
not the images. Customer, delivery point and agent names come from `source/sample-data/generate_samples.py`; every
figure is invented for the sketch.

Regenerate from this folder with the JDK 21 used by the backend:

```
java tools/GenerateMockups.java .
```
